## How to publish in 60 seconds

1. Open the `.md` post file → Select All → Copy → Paste into your CMS as Markdown (or HTML convert).
2. If images break after paste, upload the listed PNGs from `docs/marketing/assets/` and replace the broken image blocks.
3. Copy the meta title + meta description from the table above into your CMS SEO panel.
4. Set the OG image to the cover file listed for that post.
5. Publish.
